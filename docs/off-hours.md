# OFF-HOURS（趣味の記録）

トップページの TIMELINE の下に置く、仕事の外の記録です。アニメ・音楽・イベント・同人作品を、カテゴリごとに 1 件 1 枚のカードで並べます（PC 4 列・タブレット 2 列・スマホ 1 列）。

> コードの外で、観て、聴いて、手に取って、足を運んだもの。

## 記録の付け方

Google Sheets の **`OffHours`** タブに 1 行ずつ足します（行の順番は自由。サイト側で日付の新しい順に並べ替えます）。

| 列 | 必須 | 書くこと |
|---|---|---|
| `date` | ○ | 見終えた日・聴いた日・行った日・買った日。セルをダブルクリックすると日付を選べます（表示は `yyyy-mm-dd`） |
| `category` | ○ | ドロップダウンから「アニメ / 音楽 / イベント / 同人作品」 |
| `title` | ○ | 作品名・曲名・イベント名 |
| `subtitle` | | 放送クール、アーティスト、会場、サークル名など |
| `url` | | 公式サイトや作品ページ（`https://` のみ。Spotify の曲 URL もここに） |
| `image` | | 画像の URL か `/off-hours/<ファイル名>.webp`。空ならカテゴリのアイコンを表示 |

- 表示は 64px 角のサムネイル＋タイトル＋「日付 · subtitle」のカードです。件数はアニメ 8 / 音楽 12 / イベント 8 / 同人作品 4（スマホは 4 / 6 / 4 / 4）。日付はイベントだけ日まで（`2026.08.17`）、ほかは年月まで（`2026.10`）です。
- 記録が 1 件も無いカテゴリの箱は出しません。全カテゴリが空ならセクションごと出しません。
- 自分で撮った写真は `public/off-hours/` に置いてコミットします（240px 角程度で十分）。PWA の precache からは外してあり、表示されたものだけキャッシュします。

## 守ること（シートは公開物です）

サイトの API キーはブラウザに配られるため、**シートの全タブ・全列は誰でも読めます**。画面で隠すフラグは保護になりません。見られて困るものは書かないでください。

- **未来の日付は表示しません。** イベントは当日も出さず、翌日から表示します（居場所を知らせないため）。予定もシートには書かないでください。
- **同人作品は全年齢のものだけを書きます。** 念のため、DLsite の URL は全年齢フロア（`home` / `comic` / `soft`）以外なら行ごと捨てます。同人作品の画像は使いません（`image` を書いても表示しません）。
- 価格・購入数・メモのような私的な情報は列ごと作りません。
- 写真は EXIF（特に GPS）を消し、チケット・QR コード・他の人の顔が写ったものは使いません。公式のキービジュアルも転載しません。
- 外部の画像は `referrerPolicy="no-referrer"`・`loading="lazy"` で読み込み、読めなければアイコンに戻します。

## 決めたこと（仕様の経緯）

| 論点 | 決定 | 理由 |
|---|---|---|
| 名前 | **OFF-HOURS** | 仕事のセクションとの境目が一目で分かり、カテゴリが増えても古くならない。`Records` や `LOG` は TIMELINE と意味が重なる |
| シート | 1 枚（`OffHours`）にまとめる | 読み込みが 1 回で済み（Sheets の毎分クォータを全訪問者で分け合うため）、入力欄も 1 つで済む |
| トップの見せ方 | カテゴリごとの見出し＋カード（4 列） | 日付順の 1 本のフィードだと、頻度の低いイベントや同人作品が埋もれる。2026-11 に「箱に 3 件」から、曲が一覧しやすいカードの並びに変えた |
| アニメの出典 | 手入力の記録＋Annict の視聴記録 | Annict の「見てる / 見た」は 6 時間ごとにシートへ同期済みなので、二重に入力しなくて済む。視聴日が無いので放送クールの新しい順 |
| 一覧ページ | v1 では作らない | Timeline と同じく、トップだけで完結させる。データはシートに残るので後から足せる |
| 旧 `/hobbys`・アニメ 3 ページ | 撤去済み（トップへリダイレクト） | 中身が空・送信先の無いフォームを含んでいたため、フッターの刷新と合わせて削除した |
| DLsite の表記 | 「同人作品」 | サイト名だけで成人向けを連想されやすいため |

## アニメ（Annict の視聴記録）

アニメは手入力の記録のあとに、Annict の「見てる」「見た」を並べます。Annict からシート `all-watching-anime` / `all-watched-anime` へは Apps Script が 6 時間ごとに同期しています。サイトは同期済みのシートを読むだけで、Annict の API は呼びません。

- 並び順は放送クール（`release_season`、例 `2026年夏`）の新しい順。視聴中のものは「· 視聴中」と出します。
- 画像は `official_site_twitter_image_url`、リンクは `official_site_url`（どちらも `https://` のみ）。
- Annict で「見た / 見てる」にした作品はそのままサイトに出ます。出したくない作品は Annict 側で記録を外してください。

## Spotify の「最近よく聴いている曲」

音楽は手入力の記録のあとに、直近 4 週間のトップトラックを最大 12 曲出します（Vercel Function `api/spotify.js` が 1 日 1 回だけ取得）。再生中の曲や再生履歴は取りません（生活時間が分かってしまうため）。権限は `user-top-read` だけで、explicit の曲は除きます。設定するまでは何も出ません。手順は [spotify-setup.md](./spotify-setup.md)。
